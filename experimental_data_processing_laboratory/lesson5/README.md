
# Exercise 5.0 - Creating the `Position` class (`exercise5.0/`)

Implement a `Position` class that describes a point in space, following these guidelines:

1. Use three Cartesian coordinates as private data members.
2. Define a default constructor that creates a point at (0,0,0).
3. Define a constructor that takes three `double` numbers as arguments, corresponding to the coordinates of the point.
4. Define methods to return the coordinates of the point in Cartesian, spherical, and cylindrical coordinate systems.
5. Define a method that calculates the distance to another point.

Verify the class by creating a small program that reads the Cartesian coordinates of a point from the command line and prints its coordinates in spherical and cylindrical systems.

# Exercise 5.1 - Creating the `Particle` and `Electron` classes (`exercise5.1/`)

Let's define two classes to represent the sources of the field (electric in this case).

- Create a `Particle` class characterized by having a mass and a charge, with the following methods:
    1. A constructor with mass and charge as arguments.
    2. Accessor methods for mass and charge values.
    3. A method to print these values.
- Since we want this class to be the base class for other classes, declare the data members as `protected`.
- Create, using inheritance, a derived class `Electron` which, being a `Particle` with known mass and charge (values can be found on [Wikipedia](https://en.wikipedia.org/wiki/Electron)), has only a default constructor that correctly initializes the data members. Modify the print method to indicate that it is an electron.

Verify that the new classes and inheritance work correctly:
1. Dynamically instantiate an object for each class.
2. Check that all objects use the accessor methods for mass and charge from `Particle`, but the print method from the derived classes.

# Exercise 5.2 - Creating the `VectorField` and `PointMass` classes (`exercise5.2/`)

To solve problems related to electrostatics or gravity, let's try a modeling approach based on two main elements: a representation of the vector field and a representation of the sources of the vector fields.

Define a `VectorField` class: in many cases in physics, a vector is associated with a point in space. For example, a force has a point of application, or the vectors of the electric and gravitational fields have values that vary from point to point in space.

This exercise requires building a `VectorField` class, which inherits from the `Position` class and adds:
1. The three components of a vector to the position.
2. Methods to access and/or modify the vector.
3. Constructors, in particular the constructor `VectorField(const Position&)` that creates a zero vector at the assigned position.
4. A method `double Magnitude() const` that returns the length of the vector.
5. Overloading of `operator+` and `operator+=` to easily sum fields.
