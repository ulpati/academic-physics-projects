# Computer Science Lab - 8

**Summary:** Basic exercises in C++: data structures, functions, headers and sources.

## Exercise 1 - Hello World struct

Write a C++ program in which:

- Struct for complex numbers
- Function to print complex numbers
- Function to compute modulus of complex numbers
- Function to sum complex numbers


## Exercise 2 - Swap by reference or pointer
Write a C++ program in which:
- Function that swaps by reference
- Function that swaps with pointers

Create a support file `functions.cc` and the corresponding `functions.h`

## Exercise 4 - Random numbers
Write a C++ program in which:
- Generate 1000 random numbers from 0 to 100
- Print the average

## Exercise 5 - Function for exercise 1
Write a C++ program in which:
- Move exercise 1 logic into a function

## Exercise 6 - Distance between points
Write a C++ program in which:
- Create a struct with coordinates and distances for a point in 2 dimensions
- Function to calculate the distance from the origin
- Function to calculate the average
- Read the coordinates of the points from the file `data.dat`
- Print the average
