# Computer Science Lab - 10

**Summary:** Basic exercises in C++: Data filtering and Error bar plot

## Exercise 1 - ROOT data filtering

Write a C++ program in which:

- Write a struct point2d for the coordinates
- Write a function that calculates the distance between a point and the center of the circle at (0.5,0.5)
- Read the coordinates from the file data1.dat
- Plot the points on a graph with different colors for inside/outside the circle (radius 0.5)
- Save the plot as es1.png


## Exercise 2 - ROOT Error bar plot
Write a C++ program to plot the coordinates of an object in uniformly accelerated motion:

- Read the coordinates from the file data2.dat considering the error on the x axis as zero and on the y axis as constant 0.1
- Plot the coordinates on the graph
- Fit using the parametric form $y(t) = 1/2 \cdot a \cdot t^2$
- Save the plot as es2.png
