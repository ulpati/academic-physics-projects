## Exercise 1 - Hello World in C++

Write a C++ program that displays the phrase "Hello World!" on screen.

1. Open a terminal and create a new file called `exercise1.cc`, with
`code` a C++ program that displays the phrase "Hello World!" on screen.

2. Compile using:
```bash
g++ -o prog1 exercise1.cc
```
where `g++` is the C++ compiler, `-o` is the option to specify the name of the
executable that will be created by `g++`.

3. Run the program with:
```bash
./prog1
```
and check the output.

## Exercise 2 - Calculate rectangle area and perimeter

Write a C++ program that calculates the area and perimeter of a rectangle.

1. Open a new file `exercise2.cc`, declare double precision variables (`double`) for the `base` and `height` of the rectangle.

2. Assign a `base` of `5.0` and a height of `2.0`.

3. Write the formulas for the area and perimeter of the rectangle using C++ variables.

4. Print the results on screen using `cout`.

5. Compile the code with `g++`, calling the executable `prog2`.

6. Run the code and check the output.

## Exercise 3 - Makefile

Write a simple `makefile` in which:

1. the previous exercises are compiled with:
```bash
make prog1
make prog2
```

2. all exercises are compiled with:
```bash
make
```

3. `prog2` is automatically executed with:
```bash
make esegui
```

4. all binaries generated by the `make` command are removed with:
```bash
make clean
```

## Exercise 4 - Fix a program

Identify and correct the syntax errors present in the following program,
also with the help of the output produced by the `g++` compiler after copying the
content to the file `exercise4.cc`:
```c++
// File content exercise4.cc
#include <iostream>
#include <cmath>
using namespace std

int main()
{
  const double angolo = 9;
  const int a = 2, b = 3, somma = 0;

  somma=a+b

  cout << "sin(9) = " <<sin(angolo) << endl;
  cout << "somma = " << somma << "\n";

return   0;
}
```
Identify lines of code that could be improved with proper
indentation.

## Exercise 7 - Temperature conversion 1

Write a C++ program that can convert a temperature from
Celsius to Kelvin using the equation:
```
T(Kelvin) = T(Celsius) + 273.15
```
where the user can enter the input temperature in Celsius using `cin`.

Verify the following conversions:
- 20 °C -> 293.15 K
- 30 °C -> 303.15 K
