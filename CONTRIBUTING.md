# Contributing to Academic Physics Projects

Thank you for your interest in contributing to this collection of academic physics projects! This repository contains educational materials from university coursework, and contributions are welcome to improve code quality, documentation, and learning resources.

## 🐛 Reporting Issues

If you find bugs, errors in code, or unclear documentation, please open an issue with:
- A clear, descriptive title
- Description of the problem and expected behavior
- Steps to reproduce (which project/lesson, compilation commands)
- Environment details (OS, compiler version, Python version if applicable)
- Error messages or compilation errors

## 💡 Suggestions and Improvements

Contributions can include:
- Bug fixes in existing code
- Improved code comments and documentation
- Additional explanations or theoretical background
- Performance optimizations
- Alternative implementations or approaches
- Corrections to physics/mathematics
- Additional test cases or validation

## 🔧 How to Contribute Code

### Workflow
1. Fork the repository and create a feature branch
2. Make your changes following the existing code style
3. Test your changes (compile and run the code)
4. Update documentation if needed
5. Open a Pull Request with a clear description

### Coding Standards

**For C++ Projects:**
- Follow existing code patterns and indentation
- Add meaningful comments explaining physics concepts
- Use clear variable names (avoid single letters except for standard physics notation)
- Include compilation instructions if modified

**For Python Projects:**
- Follow PEP 8 style guidelines
- Add docstrings to functions
- Include comments explaining physics/algorithms
- Ensure Jupyter notebooks have clear markdown explanations

### Testing
- Compile and run C++ code to ensure it works
- For Python, test notebooks by running all cells
- Verify output makes physical sense

## 📝 Pull Request Checklist
- [ ] Code compiles/runs without errors
- [ ] Comments and documentation updated
- [ ] Physics/mathematics is correct
- [ ] Follows existing code style
- [ ] Clear commit messages
