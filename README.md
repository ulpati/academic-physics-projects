## 🎯 Overview

This repository contains a collection of academic projects developed during my Physics degree program, showcasing computational physics simulations, scientific data analysis, and advanced programming techniques. The projects span from fundamental computer science concepts to specialized physics simulations using Monte Carlo methods and statistical mechanics.

These projects represent the evolution from basic C++ programming to complex scientific computing applications, demonstrating proficiency in both object-oriented programming and computational physics methodologies.

## 📚 Projects

### 1. Statistical Physics
**Period**: 2022  
**Language**: Python  
**Topics**: Monte Carlo simulations, statistical mechanics

Introduction to computational statistical physics:
- **Ising Model** - Ferromagnetic phase transition simulations
- **Random Walks** - Stochastic processes and diffusion
- **SIR Model** - Epidemic spreading dynamics
- **Monte Carlo Methods** - Statistical sampling techniques

[📂 View folder](./statistical_physics)

## 🚀 Installation

### Prerequisites

```bash
# For C++ projects
sudo apt-get install build-essential cmake

# For Python projects
python3 -m pip install numpy matplotlib scipy jupyter
```

### Setup

```bash
# Clone repository
git clone https://github.com/ulpati/academic-physics-projects.git
cd academic-physics-projects

# Navigate to specific project
cd statistical_physics  # or computer_science_cplusplus, etc.

# Follow project-specific README for build/run instructions
```
